# koakuma 前端设计规范

本文件是前端布局与样式的唯一参考规范。改动前必须阅读；实现以离线、轻量、低内存为前提。

## 1. 设计原则

- 信息优先：设备、实时速率、历史曲线按操作顺序排列。
- 完全离线：仅使用 web/ 现有四个内嵌资源；系统字体、内联 SVG、data URI，不新增静态文件。
- 中文界面；语义化结构；键盘焦点可见；尊重 prefers-reduced-motion。
- 样式只通过语义 token 与组件类实现，不在业务元素上散落颜色值。

## 2. 页面结构分区

~~~text
.page（最大宽 1240，居中）
├─ 页头 .header：品牌、产品说明、右上角明暗切换
└─ main（纵向间距 18）
   ├─ 设备选择区 .controls：设备多选、已选计数、全选/清空、接口状态
   ├─ 实时卡片区 .cards：RX/TX 两张卡，单设备速率或多设备合计，5 秒更新
   └─ 历史曲线区 .history
      ├─ 区头：标题、说明、手动刷新/重置
      ├─ 工具栏 .history-tools：显示方式、叠加指标、预设范围、自定义从/至、查看
      ├─ 图表容器 #charts-container：分开多图或叠加单图，自适应宽度
      └─ 提示 #chart-hint：数据点计数、时间范围、刷新状态、错误
~~~

- 桌面 ≥1024：双实时卡片并排；工具栏流式排列，查看按钮靠右。
- 移动 ≤600：实时卡片与设备芯片单列；工具栏两列等宽，查看按钮独占一行；图表高 250px。
- 卡片顺序即阅读顺序，不使用横向滚动承载主要操作。

## 3. 字号体系

| token | 字号 | 场景 |
|---|---:|---|
| --fs-caption | 12px | 标签、辅助说明、状态、计数、角标 |
| --fs-secondary | 13px | 副标题、设备芯片、移动端输入 |
| --fs-body | 14px | 正文、按钮、表单、图表标题 |
| --fs-control | 16px | 区块标题、重要控件（按需） |
| --fs-title | 20px | 页面主标题 |
| --fs-number | 28px | 实时速率数字大屏 |

移动主标题可用 18px、速率 26px；数字用 tabular-nums。正文行高 1.55，标题 1.3–1.4。不得新增无语义字号。

## 5. 圆角与连续曲率

- 大卡片：16px；内嵌区域：12px；按钮：8–10px；角标：6–7px。
- 品牌标记使用 16px、桌面主题按钮使用 14px、移动端两者使用 13px 圆角，以柔和圆角近似连续曲率。
- .squircle 只设置 border-radius，禁止对承载图标、文字或按钮边框的元素使用 clip-path/mask，避免内容和上下边缘被裁切。
- 原生 border-radius 在所有浏览器中行为一致，无需额外降级；焦点轮廓保持完整可见。
- 大卡片保留普通圆角以兼顾阴影、边框与渲染成本；.squircle 只用于小型视觉焦点。

## 6. 动效规范（弹簧，ζ=1）

- 所有交互动效统一为**临界阻尼弹簧，阻尼比 ζ=1**；不得使用回弹、过冲或弹跳 easing。
- app.js 的 springTo() 用 requestAnimationFrame 与半隐式欧拉求解 a=-2ωv-ω²(x-target)，刚度可配置；用于按钮、芯片、主题按钮按下/释放。
- CSS 使用 --spring: linear(...) 的临界阻尼采样曲线；颜色/边框 300–420ms，用于芯片选中、主题切换。
- 图表出现使用同曲线的透明度与 10px 位移；.chart-enter 一次性播放，不循环。
- 减少动态偏好下直接到终态；禁用状态不触发操作。

## 7. 组件规范

- 主按钮：主色填充，用于“查看”；次按钮：柔和底与边框，用于全选、清空、刷新、重置。
- 芯片：按钮语义与 aria-pressed；选中显示主色、字重和 ✓；本机保留 ★。
- 表单：标签置于控件上方；38px 高；输入原生日期时间；焦点 2px 外描边。
- 实时卡：左侧 3px RX/TX 语义条，数值不换行挤压，长单位允许断行。
- 图表：分开模式 RX/TX 固定语义色；叠加模式设备同色，TX 在“双指标”时用虚线。
- 状态与错误保留 live region；空状态、请求失败、点计数不可省略。

## 8. 响应式与资源约束

- 网格子项统一 min-width: 0；表单 max-width: 100%；移动芯片长文本可换行。
- 页面最小支持 280px；≤600px 控件可触达，主题按钮至少 42px。
- 不引入框架、网络字体、第三方动效库或新图表库；优先复用现有 DOM 与 Chart 实例。
- 验收必须覆盖桌面/移动、明/暗主题、分开/叠加、自定义暂停/重置恢复、无横向溢出。
